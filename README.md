# Безопасность котельного оборудования: интерактивный учебный ресурс

Учебный веб-проект по техносферной безопасности, посвященный профилактике аварий и разгерметизации котельного оборудования. Сайт сочетает в себе теоретический материал, интерактивные инструменты для подготовки и элементы геймификации.

## 📌 О проекте

Проект представляет собой одностраничный лендинг, выполненный в строгой темной цветовой гамме (графит и золото). Он предназначен для студентов, изучающих охрану труда, и ответственных лиц (в рамках учебной имитации), которым необходимо подготовиться к работам на объектах повышенной опасности.

**Ключевые возможности:**
- **Интерактивная схема факторов:** Нажатие на блоки схемы («Контроль давления», «Обучение персонала» и др.) открывает модальное окно с подробным пояснением и ссылкой на нормативную базу.
- **Карточки модулей:** Краткое описание трех инструментов (Планировщик, Тренажёр аварий, Мониторинг СИЗ) с возможностью узнать подробности.
- **Мой чек-лист (Рабочий инструмент):** Раздел, где пользователь может добавлять свои правила безопасности. Данные сохраняются в `localStorage` браузера, что позволяет использовать его как личную памятку при повторных визитах.
- **Адаптивность:** Интерфейс корректно отображается как на десктопных экранах, так и на мобильных устройствах (ширина от 375px).
- **Доступность:** Основные интерактивные элементы доступны для навигации с клавиатуры, реализованы состояния фокуса.

## 🛠 Стек технологий

- **HTML5:** Семантическая разметка, формы, модальные окна.
- **CSS3:** Темная тема, адаптивная верстка (Flexbox, CSS Grid), анимации переходов, псевдоэлементы.
- **Vanilla JavaScript (ES6):** Обработка событий, валидация форм, работа с DOM, сохранение данных в `localStorage`.
- **Внешние ресурсы:** Изображения с фотостока Unsplash (без наложения ИИ-фильтров).

## 🚀 Как запустить

1. Скачайте все три файла (`index.html`, `styles.css`, `script.js`) в одну папку.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
3. Альтернативный вариант: откройте папку в VS Code и запустите проект через расширение **Live Server**.

## 📚 Источники и границы применения

Материал опирается на проверенные первичные источники:
- **Приказ Ростехнадзора от 15.12.2020 № 536** «Правила промышленной безопасности при использовании оборудования, работающего под избыточным давлением» (Проверено: 29.09.2026. *Примечание: срок действия указанной редакции ограничен, проверяйте актуальность*).
- **Приказ Ростехнадзора от 28.11.2022 № 411** (Руководство по оценке риска аварий на трубопроводах с взрывопожароопасными жидкостями).

## ⚠️ Ограничения и безопасность

- **Не является разрешением на работы:** Данный ресурс создан исключительно в учебных целях. Он не заменяет производственные инструкции, наряд-допуски или официальные нормативные документы.
- **Хранение данных:** Правила, добавленные в раздел «Мой чек-лист», сохраняются только в локальном хранилище вашего браузера (`localStorage`). Очистка кэша браузера приведет к удалению ваших записей.
- **Безопасность ввода:** Все внешние строки, добавляемые пользователем, выводятся исключительно через `textContent` (защита от XSS-атак). Ссылки на внешние ресурсы проверяются.
